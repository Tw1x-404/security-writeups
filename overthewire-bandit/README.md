# OverTheWire Bandit

Bandit is a beginner wargame by OverTheWire that teaches Linux and the
command line. Each level is a small challenge that you solve on a remote
server via SSH.

I use this folder to document how I solved each level and what I learned.
Passwords are not included, as OverTheWire asks players not to publish them.

## What I learned so far

- Connecting to remote servers with SSH
- Navigating the file system and reading files
- Searching for files with find and grep
- Working with permissions and hidden files
